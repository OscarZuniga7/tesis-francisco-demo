# Modelamiento de humedad mediante redes neuronales

## Descripción
Repositorio de demostración de un proyecto de ingeniería que combina modelamiento físico, métodos numéricos y redes neuronales artificiales.

## Objetivo
Mostrar la organización de modelos computacionales aplicados a la simulación de procesos físicos.

## Estructura
- PINN: redes neuronales informadas por principios físicos.
- DNN: modelos de redes neuronales profundas.
- DNN-Python: implementaciones en Python.

## Estado del proyecto
Repositorio demostrativo en construcción. No contiene todavía los códigos ni los resultados originales de la tesis.
